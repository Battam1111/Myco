Cultivation succession FSM (L1/GOVERNANCE §3.2; per L0/cards/COV06_no_abandonment_succession (cultivator mortality))
============================================================

Substrate-ID INVARIANT across all transitions (P1.c). Only Cultivator-side changes.


STATES (sub-states of alive; L0 §I1):
  alive::normal       — heartbeat fresh; full daily + CI operations
  alive::legacy       — heartbeat stale; daily ops continue, CI FROZEN
                        except `successor_chain` mutation
  alive::orphaned     — legacy_window elapsed OR empty chain at legacy entry;
                        operational ceiling enforced
  alive::archived     — terminal-non-destroyed via L0/cards/LB_living_bets §4 (retirement) bet-retirement;
                        state_dir preserved; no metabolism; cold-readable

Also (L1/CONTINUITY §5): alive::quarantined (orthogonal sub-state).


TRANSITION MATRIX:
==================

[T1] normal -> legacy
     Trigger:  heartbeat stale beyond threshold (default 90 anchor-days)
     Emit:     `cultivator_heartbeat_stale` (anchor-side)
     Effect:   CI FROZEN except `successor_chain` mutation;
               daily ops continue.

[T2] legacy -> normal  (vacation / hardware-failure recovery)
     Trigger:  fresh `liveness_heartbeat` from prior Cultivator pubkey
     Effect:   resume normal (no succession event).

[T3] legacy -> normal  (succession activation)
     Trigger:  chain-head successor signs
               `succession_acceptance` { substrate_id, successor_pubkey,
                 prior_cultivator_pubkey, anchor_surface_timestamp, signature }
     Emit:     `succession_completed:{successor_pubkey}` (CI, compression-invariant)
     Effect:   appends to owner_key_history; -> alive::normal.

[T4] legacy -> orphaned
     Trigger:  legacy_window elapsed (default 365 anchor-days)
               OR empty successor_chain at legacy entry
     Emit:     `cultivation_orphaned:{prior_cultivator_pubkey,
                                       anchor_surface_timestamp}`
               (CI, compression-invariant)
     Effect:   operational ceiling (see CEILING below).

[T5] orphaned -> normal  (exceptional recovery)
     Trigger:  court-attested key recovery (cryptographic mechanism
               out-of-scope v0.9; honor-system per L0/cards/AS_anchor_surface §6 (recoveries)).
               Successor presents acceptance + recovery proof reference.
     Emit:     `cultivation_recovered:{successor_pubkey,
                                        recovery_proof_reference}`
               (CI, compression-invariant)

[T6] orphaned -> destroyed  (terminal default)
     Trigger:  orphaned_terminal_window elapsed (default 730 anchor-days)
               AND genesis-time choice == self_euthanasia
     Emit:     `endogenous_mortality_proposal:cultivation_orphaned_terminal`

[T7] orphaned -> archived  (terminal via bet-retirement)
     Trigger:  orphaned_terminal_window elapsed
               AND genesis-time choice == bet_retirement
     Effect:   state_dir preserved with anchor `bet_retirement_seal`;
               cold-readable forensic; recoverable by future Cultivator.

[T8] orphaned -> orphaned  (indefinite)
     Trigger:  genesis-time choice == indefinite_orphan
     Effect:   ceiling preserved indefinitely.


OPERATIONAL CEILING (alive::orphaned):
======================================
PERMITTED:
  - per-cycle metabolism
  - sporocarp fruiting (observability + mortality only)
  - immune signals
  - observatory
  - P2 admission
  - P3 daily-class

FORBIDDEN:
  - P3 CI mutations
  - new peer pins
  - F18 compression_rule_registry mutation
  - F19 cost_budget_thresholds mutation
  - F20 telos_alignment_metric_definition mutation

REVERSION:
  - successor MAY present `succession_acceptance` any time -> alive::normal.


WATCHDOGS:
==========
- Heartbeat query cadence: 1/metabolic-cycle OR 1/24h, whichever more frequent.
- Anchor unreachable -> emit `cultivator_heartbeat_query_failed`.
- Sustained > 7 anchor-days -> emit `anchor_surface_partition` observability
  (separate signal; NOT a sub-state transition).

PROTECTIONS (L0/cards/P07_mortality §4 (substrate irreducible commitments) + L1/GOVERNANCE §1.2):
- `cultivation_orphaned` cannot be suppressed by Cultivator pressure
  (P7 + classifier fixed-point).
- Cultivation_orphaned / cultivation_recovered / succession_completed
  / bet_retired_proposal / bet_retired threshold + update-rule + emergence-rule
  are CI (L1/GOVERNANCE §1.2).


POST-M-ANCHOR-3 ENFORCEMENT:
============================
- Refuse `successor_chain` mutation unattested against anchor-fetched cultivator_pubkey.
- Refuse `succession_acceptance` whose `prior_cultivator_pubkey`
  != anchor's last-active.
- Operational ceiling enforced via classifier (forbidden mutations -> `untyped` C14).
